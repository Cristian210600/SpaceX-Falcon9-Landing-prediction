# Încărcarea proiectului pe GitHub

Repository-ul indicat este:
https://github.com/Cristian210600/SpaceX-Falcon9-Landing-prediction

## Din browser

1. Dezarhivează pachetul pe calculator.
2. Deschide repository-ul tău și verifică dacă există deja fișiere pe care vrei să le păstrezi.
3. Alege **Add file → Upload files**.
4. Trage conținutul folderului `SpaceX-Falcon9-Landing-prediction` în pagină: README, folderele și fișierele de configurare. Nu încărca doar arhiva ZIP.
5. Dacă un fișier există deja, compară-l cu noua versiune înainte de înlocuire.
6. Scrie un mesaj precum `Add capstone notebooks, data, dashboard and documentation`, apoi salvează modificările.
7. Deschide repository-ul într-o fereastră privată pentru a verifica accesul evaluatorului și deschide câteva notebookuri.

## Pentru predarea la curs

- README trebuie să apară pe prima pagină a repository-ului.
- Folderul `notebooks` trebuie să conțină toate cele șapte fișiere `.ipynb`.
- În `app` trebuie să existe `spacex_dash_app.py`.
- PDF-ul revizuit are 41 de pagini și conține linkul GitHub pe slide-urile de metodologie și rezultate.
- Include în PDF o captură reală a hărții Folium, cu fundal geografic și marcaje.
- Exportă din nou prezentarea ca PDF și trimite versiunea actualizată în câmpul cerut de platformă.
- În câmpul destinat URL-ului GitHub, pune adresa repository-ului, nu adresa unui fișier local sau a unui ZIP.

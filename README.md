# 🚀 SpaceX Falcon 9 First-Stage Landing Prediction

## IBM Applied Data Science Capstone Project

This project analyzes historical SpaceX Falcon 9 launch data and builds machine learning models to predict whether the first stage of the rocket will successfully land.

The project combines data collection, data wrangling, exploratory data analysis, SQL, geospatial visualization, interactive dashboards, and classification models into a complete end-to-end data science workflow.

---

## 📌 Project Overview

Reusable rocket technology can significantly reduce launch costs. One of the key questions is whether the first stage of a Falcon 9 launch can be successfully recovered.

The objective of this project is to investigate the factors associated with first-stage landing outcomes and build classification models that can predict successful landings.

The analysis focuses on:

- Launch site
- Payload mass
- Orbit type
- Booster version
- Flight number
- Historical launch performance
- Geographic launch-site characteristics

---

## 🎯 Objectives

The main objectives of the project are:

1. Collect SpaceX launch data using the SpaceX REST API.
2. Collect additional historical launch data through web scraping.
3. Clean and transform the collected datasets.
4. Perform exploratory data analysis using Python.
5. Analyze launch records using SQL.
6. Visualize launch sites geographically using Folium.
7. Build an interactive dashboard using Plotly Dash.
8. Train and compare several machine learning classification models.
9. Evaluate the models and identify limitations of the analysis.
